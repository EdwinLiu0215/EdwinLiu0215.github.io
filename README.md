# Edwin Liu portfolio

A static, single-page portfolio for GitHub Pages. No build step or dependencies.

## Publish

Upload `index.html`, `styles.css`, and `Resume_Version2.pdf` to the root of `EdwinSama9696/EdwinSama9696.github.io`. In repository **Settings → Pages**, set **Build and deployment** to **Deploy from a branch**, choose `main` and `/ (root)`, then save. The site should appear at `https://edwinsama9696.github.io/` after GitHub finishes publishing.

The design follows the reference site's simple editorial structure: compact navigation, spacious introduction, divided project entries, experience, education, skills, and contact. Replace the `EL` monogram with a portrait later if desired.
